# 국궁 사법 진단기

증상이나 궁금한 것을 키워드로 입력하면 원인, 원리, 교정법, 근거 원문을 보여 주는 국궁(전통 활쏘기) 자세 교정 도우미입니다.

> 정곡을 맞히지 못하면 원인을 자신에게서 찾는다 — 반구저기신(反求諸其身)

## 사용

- 웹: GitHub Pages 주소에서 바로 엽니다.
- 오프라인: `index.html` 파일 하나를 휴대폰이나 PC 브라우저로 열면 됩니다.

검색 예: `화살이 앞날 때`, `시위가 팔을 때려요`, `붕어죽`, `발시는 어떻게`, `바람`

## 방향 표기

앞·뒤는 줌손 기준입니다. 줌손 손바닥이 향한 쪽이 **앞**, 손등 쪽이 **뒤**입니다. 그래서 우궁·좌궁을 가리지 않고 같은 설명으로 읽습니다. 발 위치처럼 과녁을 향한 방향은 '과녁 쪽·과녁 반대쪽'으로 적습니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 진단기 (단일 파일, 지식베이스 내장) |
| `data/gungdo_kb.json` | 지식베이스 원본: 진단 항목 42개, 용어 87개, 근거 원문, 자료마다 다른 설명 |

## 근거 자료

조선의 궁술(1929), 사예결해(1777), 사법비전공하(1799), 정사론(1872), 무신수지(1809), 조선일보 「조선의 궁도와 사풍」(1934), 황학정 궁도입문서, 국궁신문 기사(사벽과 교정·비정비팔·깍지손 쥐기 등), 활터 교범·교안.

자료끼리 설명이 다른 곳은 한쪽을 고르지 않고 '자료마다 다른 설명'에 나란히 실었습니다. 역학 해설과 어림 수치는 이 자료에서 덧붙인 것이며 옛 문헌의 말이 아닙니다.

## 지식베이스 갱신

`data/gungdo_kb.json`을 고친 뒤 `index.html` 안의 `<script id="kb" type="application/json">` 블록을 같은 내용으로 바꾸면 됩니다.
